# Плавающий калькулятор — утверждённый образец (ЗАФИКСИРОВАН)

Файл `float-calculator.html` — рабочий образец, утверждён владельцем. Не менять без его слова.

- Два режима: «Обычный» и «Стройка» (площадь и периметр, объём, диагональ, уклон, запас в %).
- Окно перетаскивается за заголовок; булавка закрепляет поверх страницы (position: fixed), без булавки окно прокручивается со страницей; сворачивается в плашку; положение хранится в localStorage.
- Стиль: графитовый корпус, красные уголки, шрифты Onest и IBM Plex Mono, размерная линия под дисплеем, лента двух последних операций.
- Клавиатура: цифры, + − * /, Enter, Backspace, Esc, %.
- Находится в разделе «Расчёт смет». Слово «калькулятор» в названии раздела и меню не используется.
- Переносится на сайт как самостоятельный блок (html + css + js в static/), без внешних библиотек.
