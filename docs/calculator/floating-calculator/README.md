# Плавающий калькулятор — утверждённый образец (ЗАФИКСИРОВАН)

Файл `float-calculator.html` — рабочий образец, утверждён владельцем. Не менять без его слова.

- Два режима: «Обычный» и «Стройка» (площадь и периметр, объём, диагональ, уклон, запас в %).
- Окно перетаскивается за заголовок; булавка закрепляет поверх страницы (position: fixed), без булавки окно прокручивается со страницей; сворачивается в плашку; положение хранится в localStorage.
- Стиль: графитовый корпус, красные уголки, шрифты Onest и IBM Plex Mono, размерная линия под дисплеем, лента двух последних операций.
- Клавиатура: цифры, + − * /, Enter, Backspace, Esc, %.
- Находится в разделе «Расчёт смет». Слово «калькулятор» в названии раздела и меню не используется.
- Переносится на сайт как самостоятельный блок (html + css + js в static/), без внешних библиотек.

## Расширение (по просьбе владельца): вкладки «Металл», «Бетон», «Формулы»

- **Металл:** сортамент. Арматура, круг, квадрат, полоса, труба круглая и профильная считаются по формулам (плотность 7850 кг/м³). Швеллер серии У (ГОСТ 8240-97), двутавр (ГОСТ 8239-89) и уголок равнополочный (ГОСТ 8509-93) берутся из таблиц масс 1 м. Лист: толщина × 7,85 кг/м². Результат: масса 1 м, всего кг и т, общая длина.
- **Бетон:** расчётный начальный состав на 1 м³ для марок М100–М550 (цемент ПЦ 400, щебень гранитный 20–40 мм, осадка 2–4 см, заполнители сухие), с пересчётом на объём, запас, мешки по 50 кг. Допущение: насыпная плотность песка 1600, щебня 1400 кг/м³.
- **Формулы:** 9 плоских фигур и 7 объёмных тел (площадь, периметр, объём, поверхность).
- Любой результат переносится в обычный калькулятор нажатием.
- Таблицы сортамента и составов собраны из открытых источников и не сверены с оригиналами стандартов. Перед публикацией на сайте проверить по действующим ГОСТ и СТБ.
- Версия до расширения: `float-calculator.v1-approved.html` не сохранялась в репозитории, откат — по истории коммитов (коммит с утверждением образца).
