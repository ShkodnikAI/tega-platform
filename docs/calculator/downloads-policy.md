# Скачиваемые файлы сайта (решение владельца, 2026-10-18)

1. Всё, что посетитель скачивает с сайта (сметы, спецификации, списки закупки), отдаётся **только в формате PDF**. Excel, Word, CSV и другие форматы не предлагаются.
2. На **каждой странице** PDF стоит полупрозрачный водяной знак со ссылкой на сайт: `tega.plus`.
3. Письмо «смета на почту» содержит тот же PDF с водяным знаком, без других вложений.
4. PDF собирается на сервере из результата расчёта; исходные таблицы норм и цен в файл не попадают (условия лицензии на нормы НРР).

Реализация (не сделана): генерация PDF на сервере + наложение водяного знака (диагональный текст, ~15 % непрозрачности, на всех страницах), заголовок «Ориентировочный расчёт, не является офертой».

# Справка «Как считаются объёмы» (экран калькулятора)

Текст написан простым языком по методу калькулятора (`calculator-method.md`) и общим правилам обмера. Нормы НРР дословно не воспроизводятся. **До публикации текст сверяет технический эксперт с техническими частями НРР-2022** (правила подсчёта объёмов, вычет проёмов, колонны и ниши). Разбор технических частей (RTF) в библиотеке норм ещё не сделан.
